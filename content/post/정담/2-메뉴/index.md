# 정담 개발 일지 #2 - 메뉴 붙이고 잔손질

[#1]({{< ref "/post/정담/1-시작" >}})에서 뼈대는 세웠으니 이제 실제 메뉴를 넣을 차례다.
1월 16~17일 이틀 동안 커밋 6개. 큰 기능은 없고 잔손질이 대부분이었는데, 잔손질이 제일 오래 걸린다.

## 메뉴 데이터

일단 JSON 파일 하나에 박았다. 카테고리 안에 아이템 배열이 들어가는 단순한 구조.

```json
{
  "categories": [
    {
      "id": "fried",
      "name": "튀김",
      "description": "바삭한 것들",
      "items": [
        { "image": "...", "title": "간장마늘치킨", "ingredients": "닭, 마늘, 간장", "price": "$18" }
      ]
    }
  ]
}
```

`price` 를 숫자가 아니라 **문자열**로 둔 게 나중에 편했다. `$18`, `18,000원`, `시가` 같은 걸 다 넣을 수 있다.
가격 계산을 할 일이 없는 화면이라 숫자로 둘 이유가 없었다.

## 이미지 경로로 두 번 자빠짐

커밋 두 개가 연속으로 이미지 경로 고치는 거다.

```
fix: menu img issue
fix: image paths in MenuSection component
```

템플릿은 `assets/img/menu/...` 같은 상대 경로를 쓴다. Next.js에선 `public/` 이 루트라서 `/img/menu/...` 로 바뀌어야 한다.
근데 CSS 안의 `background-image` 랑 JSX의 `src` 랑 기준이 달라서 한 번에 안 잡혔다. 하나 고치면 다른 하나가 깨진다.

## 전화번호는 눌러서 걸려야 함

이게 오늘 제일 잘한 것 같다.

```
fix: update contact links to use telephone protocol
```

템플릿은 연락처 번호가 그냥 텍스트다. 근데 **식당 홈페이지는 폰으로 보는 사람이 거의 전부**고, 그 사람들이 하는 행동은 하나다. 전화 걸어서 예약하거나 위치 묻기.

```html
<a href="tel:0XX-XXX-XXXX">0XX-XXX-XXXX</a>
```

한 줄인데 "번호 외워서 전화앱 열고 누르기" 가 "탭 한 번"이 된다.

## 메뉴로 바로 내려가는 버튼

```
feat: add scroll-to-menu button functionality and styles
```

손님이 홈페이지 와서 제일 보고 싶은 건 메뉴다. 근데 Hero 아래에 About, Why Us, Stats가 쌓여 있어서 한참 스크롤해야 한다.
템플릿 기본 배치를 그대로 두되 Hero에 **메뉴로 점프하는 버튼**을 달았다.

섹션 순서를 바꿀까도 생각했는데, 템플릿 디자인이 그 순서 전제로 짜여 있어서 건드리면 여기저기 깨질 것 같았다.

## 프리로더가 안 사라짐

```
fix: enable preloader removal on component mount
```

템플릿엔 로딩 스피너가 있고, `window.load` 이벤트에서 DOM을 지우는 식으로 사라진다.
근데 Next.js에선 하이드레이션 타이밍이 달라서 **그 이벤트를 이미 놓친 뒤**인 경우가 생긴다. 그러면 스피너가 영원히 안 없어진다.

화면이 하얗게 멈춘 것처럼 보여서 제일 치명적인 버그였다. `window.load` 대신 컴포넌트 마운트 시점에 지우게 바꿔서 해결.

## 느낀 점

**정적 템플릿의 버그는 대부분 "타이밍"에서 나온다.** 이미지 경로는 30분이면 고치는데, 프리로더처럼 "이벤트를 언제 놓쳤나" 하는 건 한참 헤맨다.
`window.load` / `DOMContentLoaded` 전제로 짠 코드는 React에 올리는 순간 전부 의심해봐야 할 듯.

그리고 `tel:` 링크 같은 건 기술적으로는 아무것도 아닌데 실제 손님한텐 제일 크다. 이런 걸 놓치면 안 되겠다.

다음은 사장님이 직접 메뉴를 고칠 수 있게 관리자 페이지 만들 차례.
