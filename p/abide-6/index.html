# ABIDE 개발 일지 #6 - 성경 버전을 늘리니 UI가 줄줄이 깨졌음

03-27 17:47  fix: 성경 설정 시트 폰트 크기 확대 시 bottom overflow 수정

11개 중 7개가 설정 시트 하나에서 나왔다.

패턴이 보다.

1. 오버레이 겹친다. 묵상 화면에서 구절 미리보기를 띄우면 키보드가 올라올 때 입력창을 가린다. 모바일에서 오버레이 + 키보드는 거의 항상 문제가 된다. 화면 높이가 실시간으로 바뀌는데 오버레이는 그걸 모른다.

2. 터치 차단. 투명한 오버레이가 보이지도 않으면서 터치를 먹고 있었다. 화면은 정상인데 버튼이 안 눌린다. 제일 찾기 어려운 종류다.

3. 글자 크기가 반영이 안 된다. 설정에서 키우면 값은 바뀌는데 본문에 안 닿는다. 프로바이더까지는 갔는데 위젯이 그 값을 구독하지 않고 있었다.

4. 크기를 키우면 오버플로우. 반영되게 고쳤더니 이번엔 시트가 터진다. 01:44 에서 고정 높이로 잡아둔 게 원인. 스크롤 가능하게 바꾼다.

# 이모지를 아이콘으로 바꿈

25일에 이걸 했다.

1

refactor: replace emoji with Material Design icons throughout UI

무드 선택이나 빠른 진입 버튼에 이모지를 쓰고 있었다.

이모지는 기기·OS 버전마다 그림이 다르다. 같은 유니코드인데 안드로이드랑 iOS가 완전히 다르게 그림. 디자인을 맞출 수가 없고, 폰트가 없으면 두부(□)가 나온다.

실제로 03-26 13:40 에 “감사 무드 이모지 누락"이 있다. 아이콘으로 바꾼 뒤에도 한 군데가 남아 있었던 것.

같은 날 이것도 같이 고친다.

1

fix: restrict debug logging to debug builds, fix quota API and notification settings parsing

디버그 로그가 릴리즈 빌드에도 찍히고 있었다. 토큰이나 응답 본문이 로그에 남는다. #4에서 민감 정보 마스킹한 거랑 같은 줄기인데, 이번엔 클라이언트 쪽이었다.

# 느낀 점

“버전 하나 추가"가 UI 버그 11개를 불렀다.

기능 자체는 반나절이면 되는데, 그게 건드리는 화면이 성경 인덱스·본문·설정 시트·묵상 화면·홈 카드까지 퍼져 있었다. 옵션이 하나 늘면 조합이 곱으로 늘어난다는 걸 몸으로 배웠다.

그리고 모바일에서 오버레이랑 키보드는 항상 의심해야 한다. 11개 중 3개가 그거였다.

다음은 스트리밍이랑 Observer 깊이 판정이다. 이 시리즈에서 제일 오래 붙든 부분.
